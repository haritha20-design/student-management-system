# Student Management System

A web-based Student Management System developed using Python, Flask, MySQL, HTML, CSS, and JavaScript.

## Features

- User Registration and Login
- Student Management
- Add, View, Edit, and Delete Student Records
- Forgot Password
- Email OTP Verification
- Password Reset
- MySQL Database Integration

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Configure your database and environment variables.
5. Run the application:

   `python app.py`

## Project Purpose

This project was developed to practise Python Full Stack Development, database connectivity, user authentication, and CRUD operations.
